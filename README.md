# Loksewa Education Aid Portal (prototype, connected to Supabase)
Files: index.html (home) · students.html · sponsors.html · staff.html (staff only) · style.css · config.js (edit this) · common.js · schema.sql (run in Supabase)
Setup in 5 steps: 1) create a Supabase project (Mumbai region) 2) run schema.sql in the SQL Editor 3) paste your URL + publishable key into config.js 4) create an admin user and add them to the staff table, turn off public sign-ups 5) open index.html (or deploy the folder to Cloudflare Pages / Netlify).
All people, programs and figures in schema.sql are fictional samples.
